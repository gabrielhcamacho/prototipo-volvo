# Campeonatos e Torneios AV

Apresentação e protótipo navegável do app de campeonatos internos da Associação Volvo (Curitiba).

- `index.html`: site completo em um arquivo (apresentação, protótipo do app, painel web e apresentação guiada). Pode ser publicado direto na Vercel, sem build.
- `src/`: código-fonte. Para gerar o `index.html` de novo: `pip install pillow && python3 src/build.py`.

Dados ilustrativos.
